# 计算参数假设清单

本工具的全部计算参数都是 `config/default.toml` 中的配置项（桌面端可在“设置”中逐项修改）。下面列出默认值及依据：
- **【用户已确认】**：用户本人确认的参数（2026-10-21）；
- **【公开资料核实】**：已查到官方文本，出处见第 3 节；
- **【需确认】/【可配置假设】**：尚未确认，正式结算前请财务人员确认。

用语以 [`docs/TERMINOLOGY.md`](TERMINOLOGY.md) 为准（例如“不含增值税收入”“企业总支出”“应预扣预缴税额”“税后实发金额”）。

> 说明：本文档只陈述计算方法与参数，不构成税务意见。

## 1. 计算流程（默认参数）

**核心变量是不含增值税收入 I**（劳务报酬的每次收入，不含增值税，精确到分）。其余金额均由 I 唯一确定。**【用户已确认】**

```
不含增值税收入 I（精确到分，I ≥ 0）
  ├─ 增值税税额 V = I 达到起征点 1000 元 ? round(I × 1%) : 0
  ├─ 增值税附加税费 S = Σ 征收项目 round(V × 法定费率 × (1 − 减征比例))
  │     减征优惠：默认“是”，减征比例 50%（小规模纳税人减半征收，见 S3）
  │     城市维护建设税：默认不征收（选“是”时按纳税人所在地 7% / 5% / 1%，预填市区 7%）
  │     教育费附加：3%，默认征收（减半后实际 1.5%）
  │     地方教育附加：默认不征收（选“是”时预填 2%）
  ├─ 企业总支出 C = I + V + S（三项都由企业承担）
  ├─ 个人所得税（居民个人劳务报酬所得预扣预缴，按 I）：
  │    减除费用 D = I ≤ 4000 ? 800（I < 800 时以 I 为限）: round(I × 20%)
  │    预扣预缴应纳税所得额 T = I − D
  │    应预扣预缴税额 P = round(T × 预扣率 − 速算扣除数)（预扣率表二）
  └─ 税后实发金额 = I − P（附加税费由企业承担，不从中扣除）
```

round = 四舍五入到分（MidpointAwayFromZero），每一步单独舍入；附加税费各项目按“法定费率 × (1 − 减征比例)”一次计算后分别按分舍入再相加，减征前金额 = round(V × 法定费率)，减征额 = 减征前金额 − 实际金额。

- **按不含增值税收入计算（主入口）**：CLI `labor-fee forward`、Web/API `/api/forward?net_income=`、库函数 `forward`。
- **按税后实发金额测算**：输入税后实发金额，求出 I 再计算全部金额（见第 4 节）。
- **按企业总支出测算**：输入企业总支出 C，求满足“计算所得企业总支出 = C”的 I；不存在时报错，不倒挤、不输出差额（见第 5 节）。

## 3. 公开出处（只列实际查到的内容）

### 3.1 个人所得税

1. **国家税务总局公告 2018 年第 61 号**《国家税务总局关于发布〈个人所得税扣缴申报管理办法（试行）〉的公告》，2018-12-21 发布，2019-01-01 起施行。
   - 国家税务总局网站：<https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3963396/content.html>（正文；附件“个人所得税税率表及预扣率表”另附）
   - 中国政府网《国务院公报》2019 年第 12 号（含附件表格）：<https://www.gov.cn/gongbao/content/2019/content_5386991.htm>
   - 第八条原文要点：“劳务报酬所得……以收入减除费用后的余额为收入额”；“减除费用：预扣预缴税款时，劳务报酬所得……每次收入不超过四千元的，减除费用按八百元计算；每次收入四千元以上的，减除费用按收入的百分之二十计算”；“以每次收入额为预扣预缴应纳税所得额……劳务报酬所得适用个人所得税预扣率表二”。
   - 附件《个人所得税预扣率表二（居民个人劳务报酬所得预扣预缴适用）》：不超过 20000 元，20%，0；超过 20000 元至 50000 元的部分，30%，2000；超过 50000 元的部分，40%，7000。
   - 第十一条：劳务报酬所得属于一次性收入的，以取得该项收入为一次；属于同一项目连续性收入的，以一个月内取得的收入为一次。
   - 同一表格也见国家税务总局辽宁省税务局问答页（2023-07-07）：<https://liaoning.chinatax.gov.cn/art/2023/7/7/art_1920_105200.html>
2. **《中华人民共和国个人所得税法》**（2018-08-31 第七次修正），国家税务总局政策法规库：<https://fgk.chinatax.gov.cn/zcfgk/c100009/c5193028/content.html>
   - 第六条：劳务报酬所得以收入减除百分之二十的费用后的余额为收入额（年度汇算口径）；第十一条：有扣缴义务人的，由扣缴义务人按月或者按次预扣预缴税款，预扣预缴办法由国务院税务主管部门制定。
3. **《中华人民共和国个人所得税法实施条例》**（国务院令第 707 号），国家税务总局网站：<https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3963364/content.html>
   - 第六条第（二）项：劳务报酬所得的范围；第十四条：“每次”的确定方法，与公告第十一条一致。

**核实结论**
- “≤4000 减 800、>4000 减 20%”与公告一致。原文是“不超过四千元”和“四千元以上”，恰好 4000 元时两种算法都是 800 元，结果一样；工具按“≤4000 减 800”处理。
- 三档预扣率和速算扣除数与表二一致。表二写的是“不超过 20000 元”和“超过 20000 元至 50000 元的部分”，工具把 20000 和 50000 都算在较低一档（上限含本数）。经验算，边界两侧税额相等：20000×20% = 20000×30% − 2000 = 4000；50000×30% − 2000 = 50000×40% − 7000 = 13000。所以含不含本数不影响税额。
- 以上规则只用于**预扣预缴**；居民个人年度汇算时劳务报酬按“收入×80%”并入综合所得，多退少补，本工具不计算汇算。

## 4. 按税后实发金额测算与校准规则

1. 测算在不含增值税收入的分位网格上找“计算所得税后实发金额 = 目标”的 I：按“是否征收增值税 / 减除费用方式 / 预扣率档次”分段，每段内先二分、再按 0.01 上下逐分校准，最后对选中的 I 计算全部金额。
2. **默认参数下税后实发金额随不含增值税收入单调不减，且收入每增加 0.01，实发金额只增加 0 或 0.01**（已对 I = 0～300,000 元逐分验证；附加税费不影响实发金额，三项全开时同样成立）。所以：
   - **不存在无解区间**：任意非负税后实发金额都能精确匹配，测算结果再计算回去到分一致（0.01～200,000 元每隔 0.37 元遍历、各分段附近 ±10 元逐分、proptest 验证）。
   - **存在多解，但只是相邻几分的“平台”**：实发金额 = I − 应预扣预缴税额，税额逐分舍入时会出现相邻的 I 得到同一实发金额（如 50000 对应 I = 63235.29 和 63235.30）。按规则取最小 I，结果中 `exact_net_income_range` 给出等效区间。默认参数下不存在不相连的多解（`other_solutions` 为空）。
   - 起征点只改变增值税及附加税费，不影响 I 和个人所得税，所以**税后实发金额在起征点处是连续的**：实发 959.99 → I 999.99（企业总支出 999.99）；实发 960.00 → I 1000.00（企业总支出 1010.15）。
3. 无解（“无法精确匹配”）和不相连的多解只会在自定义参数下出现，例如把 4000 元以上的减除比例改成 30%（实发金额向上跳，中间不可达）或 10%（向下跳，两段多解）。这两种情况都有测试：无解时取最接近的 I，标“无法精确匹配”并给出差额；多解时取最小 I，其余列为“其他可行不含增值税收入”。
4. 负数、超过两位小数的金额直接报错，不做静默舍入。

## 5. 按企业总支出测算

企业总支出 C 随不含增值税收入严格递增，但不是每个“分”都能取到：

| 类型 | 例子 | 原因 |
|---|---|---|
| 起征点不可达区间 | 企业总支出 1000.00～1010.14（共 1015 个分） | 增值税起征点 1000 元：I = 999.99 时不征收，企业总支出 999.99；I = 1000.00 时征收增值税 10.00、教育费附加 0.15（减征前 0.30），企业总支出 1010.15。区间随配置变化：不享受减征时 1000.00～1010.29；三项全征收（7%/3%/2%）并减半时 1000.00～1010.59，不减征时 1000.00～1011.19。 |
| 按分舍入形成的不可达金额 | 企业总支出 1061.16 | 增值税税额及附加税费按分舍入：I = 1050.49 → 1061.15，I = 1050.50 → 1061.17（增值税从 10.50 变为 10.51）。收入每增加 1 元，增值税约增加 0.01 元，企业总支出跳过一个分；附加税费同时进位时跳过两个分。默认参数下 1010.15～70,000 元中约 68,000 处、共约 69,000 个分（约 1%）。 |

输入不可达时**明确报错，不倒挤、不输出差额**，报错内容包括：原因（起征点 / 按分舍入），以及两侧最近的有效企业总支出和各自对应的不含增值税收入。例如：

> 企业总支出 1005.00 无对应的不含增值税收入：该金额位于增值税起征点（1000 元）形成的不可达区间。不含增值税收入 999.99 对应企业总支出 999.99，1000.00 对应 1010.15，其间的企业总支出均无对应收入。两侧最近的有效企业总支出：999.99（不含增值税收入 999.99）、1010.15（不含增值税收入 1000.00）

> 企业总支出 1061.16 无对应的不含增值税收入：增值税税额及附加税费按分舍入，不含增值税收入 1050.49 对应企业总支出 1061.15，1050.50 对应 1061.17，其间的金额不可达。两侧最近的有效企业总支出：1061.15（不含增值税收入 1050.49）、1061.17（不含增值税收入 1050.50）

CLI（`labor-fee from-cost`，`--json` 时输出 `gap` 结构，退出码 2）、Web 页面、API（`/api/from-cost` 返回 422，字段 `error`、`reason`、`gap`）和批量（输入列选“企业总支出”时，该行“测算状态”为“总支出不可达”，“备注”列写上述原因）都显示这段说明。非默认附加税费（如 1% 或 3% 征收率下 7%/3%/2% 三项全征收，减半、减征 30% 或不减征，逐项或合计舍入）下的不可达区间与提示同样经过逐分遍历测试。**【用户已确认】**
