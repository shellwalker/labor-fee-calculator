# 桌面程序界面设计（v2）

适用于 `labor-fee-desktop`（eframe/egui 0.37）。设计令牌在 `crates/desktop/src/theme.rs`，组件在 `crates/desktop/src/ui/widgets.rs`。

## 1. 设计目标

财务试算工具，用户关心“算得对不对、看得清不清、能不能核对”：

| 目标 | 做法 |
|---|---|
| 清晰 | 一屏一个任务；输入 → 结果 → 规则 从左到右；关键结果（企业总支出、应预扣预缴税额、税后实发金额）用大号指标卡置顶 |
| 可信 | 每次结果都有校验状态徽章和“算式核对”（把本次数值代入公式）；计算规则按**当前生效的计算参数**动态生成并注明政策依据；是否为内置默认参数在状态栏常驻显示（宽度足够时顶栏也显示） |
| 数字易读 | 金额统一千分位、保留到分、等宽字体（Hack）右对齐，单位“元”弱化显示；正负语义色固定 |
| 不出错 | 真空区间等无解情况用醒目的警示卡说明原因并给出可点击的最近有效值；设置逐项校验，错误就地标红并说明原因，有错时 ✔ 不可用；每项修改须点击 ✔ 确认才生效 |
| 饱满 | 内容随窗口尺寸铺满：三栏 / 两栏 / 单列自适应，各栏独立滚动；空状态也显示完整骨架（“—”占位），不留大片空白 |

## 2. 配色

默认**跟随系统**浅色/深色（`ThemePreference::System`），设置中可固定为浅色或深色，选择持久化。品牌主色为沉稳蓝，辅以青色点缀。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#F3F5F9` | `#0E131C` | 窗口底色 |
| surface | `#FFFFFF` | `#161D29` | 卡片、顶栏、状态栏 |
| surface_alt | `#F6F8FB` | `#1C2433` | 表头、斑马纹、次级底 |
| border | `#E2E7EF` | `#273043` | 1px 描边、分隔线 |
| text / text_weak | `#1B2433` / `#667085` | `#E6EAF2` / `#98A2B3` | 正文 / 说明、单位 |
| primary | `#1D4ED8` | `#5B8DEF` | 品牌、主按钮、选中导航、企业总支出 |
| primary_soft | `#E8EEFC` | `#1B2946` | 选中底、快捷示例、提示条 |
| accent | `#0D9488` | `#2DD4BF` | 规则列表圆点、图标渐变 |
| success / soft | `#15803D` / `#E6F4EA` | `#4ADE80` / `#12291D` | 校验通过、税后实发金额、成功数 |
| warning / soft | `#C2410C` / `#FDF0E6` | `#FB923C` / `#33220F` | 应预扣预缴税额、待确认、无法精确匹配 |
| error / soft | `#C81E1E` / `#FCEBEB` | `#F87171` / `#3A1818` | 错误、真空区间、错误行 |

语义固定：**蓝 = 企业总支出 / 主操作，橙 = 应预扣预缴税额 / 需注意，绿 = 税后实发金额 / 通过，红 = 错误 / 不可达**。文字与底色对比度 ≥ 4.5:1（弱化文字 ≥ 3:1）。

## 3. 字号层级

| 层级 | 字号 | 字体 | 用途 |
|---|---|---|---|
| Display | 26 | 等宽 | 指标卡金额 |
| Title | 20 | 无衬线 | 页面标题、对话框标题 |
| Section | 15.5 | 无衬线（加深色） | 卡片标题 |
| Body | 14 | 无衬线 | 正文、按钮 |
| Money | 15 / 16.5 | 等宽 | 明细金额 / 合计行 |
| Small | 12 | 无衬线 | 说明、单位、徽章、状态栏 |

中文为内嵌 LaborFee Sans SC（Noto Sans CJK SC 子集），图标为内嵌 LaborFee Icons（Noto Emoji 子集，仅界面用到的字形，避免 CJK 子集缺字），数字为 egui 自带 Hack。

## 4. 间距、圆角、阴影

- **8px 栅格**：4 / 8 / 12 / 16 / 24 / 32。卡片内边距 16，卡片间距 8～16，页面边距 20×16，对话框内边距 24。
- **圆角**：卡片 10，控件 6，徽章/快捷示例 12（胶囊），对话框 14。
- **阴影**：卡片 `0 1 6` 极淡阴影 + 1px 描边；对话框 `0 12 36`；弹出菜单 `0 4 14`。
- 控件最小高度 28，主按钮 34～36。

- **设置对话框**（模态，宽 660～920）：


  - **导航层级**：一级为分组标题（小号、弱色、不可点击），二级为页（缩进 12px）。计税口径（增值税、附加税费、个人所得税）是税收政策参数；计算规则（金额舍入、测算求解）是计算实现规则，与政策无关；通用（外观、设置存储）是程序偏好。原“舍入与测算”页混有舍入规则与反算求解参数，拆为“金额舍入”“测算求解”；原“外观”页中的保存位置说明移到“设置存储”。页名右侧小圆点：红 = 有已修改项，橙 = 有未生效项；有错误时页名后显示错误数。不再显示状态说明图例。
  - **表单行**：“标签 | 控件+单位 | ✔ ✖ 未生效 | 单项默认”，下方补充说明区依次为错误、常驻默认值提示、帮助。
  - **不显示口径状态徽章**（用户要求，第六轮）：设置窗口各页、主窗口计算规则面板都不再显示“已确认 / 已核实 / 待确认 / 实现参数”徽章，口径状态只记录在 `docs/ASSUMPTIONS.md`。“已修改”徽章与常驻提示“ℹ 当前值与默认值不同（默认：…）”重复，也去掉，只保留常驻提示 + 左侧导航红点 + 底部“与内置默认不同 N 项”计数（计数 = 常驻提示行数）。保留的功能性提示：橙色描边“未生效”与 ✔ ✖、常驻默认值提示、单项“默认”按钮。去掉徽章列后标签列加宽到 180、控件列加宽到 240，避免右侧留空。
  - **编辑态**：输入与生效值不同即为未生效：控件 1.5px 橙色描边 + warning_soft 底，出现绿色实心 ✔（悬停“确认生效（Enter）”，非法时禁用并悬停说明原因）、描边 ✖（“放弃本项修改（Esc）”）和橙色描边“未生效”标签。
  - **单项“默认”**：仅在生效值与默认不同时显示。**不弹框**：点击后只把该项输入填为内置默认值并进入未生效态，右侧出现 ✔ ✖；✔ 才生效并保存，✖ 放弃（与其他修改走同一条确认路径，避免“点了就落盘”的特例）。
  - **附加税费页**（自上而下）：
    1. **附加税费合计比例**卡片（surface_alt 底、圆角 10）：大号“6% → 3%”（默认）（减征前删除线弱色，减征后品牌色 26px）；四列表格“税费项目 / 法定费率 / 减征 / 实际征收率”+ 合计行。按已生效设置计算；本页有未生效修改时，卡片底部橙色小字“含未生效修改的预览：合计 x → 减征后 y（点击 ✔ 生效后计入）”。
    2. **减征优惠**：“享受减征优惠 ○否 ○是”（单选，否在前），选“是”时下方展开“减征比例 [50] %”；下方小字政策依据，附“财政部 税务总局公告2023年第12号”“国家税务总局政策法规库”“六税两费减免政策问答第10问”三个链接（悬停显示网址）。
    3. **征收项目**：每项一行“名称 | 是否征收 ○否 ○是 | ✔ ✖ | 标签 | 默认”。三项默认均为“是”。选“否”隐藏具体配置；选“是”展开：城市维护建设税为“纳税人所在地”三个单选，每个单选右侧一个该档税率输入框（“纳税人所在地在市区：税率 [7] %”“…在县城、镇：税率 [5] %”“…不在市区、县城或者镇：税率 [1] %”，默认选中 1% 档；各档税率均可直接修改，与默认不同时在输入框右侧常驻“（默认：7%）”小字；非法值（负数、≥100%）该行 ✔ 禁用并提示），教育费附加、地方教育附加为“征收比例 [ ] %”。档位切换、档位税率修改都属于城建这一行，同样进入未生效态，✔ 才落盘，单项“默认”恢复档位与各档税率。选择“每档右侧带输入框”而非“选中后下方出现输入框”：三档税率同时可见、可直接对照，切换档位时不出现布局跳动。单选切换与文本输入一样进入未生效态，✔ 才落盘；改回“否”时隐藏的费率恢复为生效值。可添加其他项目（名称可编辑、可删除）。
    4. **计税依据**。
  - **全部恢复默认**：左下角红字描边按钮（桌面惯例中“恢复默认”位于对话框左下，与确认类按钮分开），点击后弹出危险操作确认框：⚠ 标题、影响范围（全部计算参数和外观偏好、两个设置文件、未生效修改一并放弃、不可撤销）、当前与默认不同的项数，按钮“取消”（次）与红色实心“恢复默认”。
  - **关闭**：每项确认即保存，故去掉“保存 / 取消”，底部右侧只有“关闭”。有未生效修改时关闭（按钮、Esc、⌘W / Ctrl+W、点击窗口外）弹出“有 N 项修改尚未生效”确认框：“返回”与红色“放弃未生效的修改”。
- **关于**：图标、名称、版本、构建（git 短哈希 + 日期）、平台、许可、计算参数、政策依据链接、字体 OFL 声明、免责声明。

## 7. 交互

- 输入框回车即计算；快捷示例、最近计算一键重算；真空区间两侧按钮一键填入重算。
- 拖放表格文件到窗口任意位置进入批量页。
- 设置中选择主题即时预览，点击 ✔ 生效并保存，点击 ✖ 还原。
- 设置中焦点所在项：Enter 等同 ✔，Esc 等同 ✖；Esc 优先用于放弃该项修改，不会误关窗口；没有未生效修改时 Esc 关闭设置窗口。

| 快捷键 | macOS（原生菜单） | Windows / Linux | 作用 |
|---|---|---|---|
| 设置 | `⌘,`（应用菜单“偏好设置…”） | `Ctrl+,`（文件 › 设置…） | 打开设置窗口 |
| 打开批量文件 | `⌘O`（文件） | `Ctrl+O`（文件） | 选择表格文件 |
| 关闭窗口 | `⌘W`（窗口 › 关闭窗口） | `Ctrl+W`（文件 › 关闭窗口） | 先关闭最上层对话框（设置有未生效修改时先确认）；没有对话框时最小化主窗口，不退出 |
| 最小化 | `⌘M`（窗口 › 最小化） | — | 最小化主窗口 |
| 退出 | `⌘Q` | `Ctrl+Q`、`Alt+F4` | 退出程序 |

macOS 的“最小化”“关闭窗口”为自定义菜单项（`ViewportCommand::Minimized(true)`），不使用 muda 预置的 Close Window（会关闭主窗口并退出程序）。

## 8. 自检

`cargo test -p labor-fee-desktop --test screenshots -- --ignored` 用 wgpu 离屏渲染各页（浅色/深色、默认尺寸与最小尺寸），已迭代三轮：
1. 第一轮：中栏过窄导致指标卡竖排 → 收窄输入/规则栏并下调三列阈值；设置对话框因竖向分隔线随可用高度增长而逐帧变高 → 改为固定高度分隔线并限制滚动区高度；对话框内边距过小 → 统一 24px 对话框外框。
2. 第二轮：个税指标卡说明换行导致三卡不等高 → 说明改单行截断；左右箭头在等宽字体中显示过小 → 改用中文字体中的 ←/→；状态条在中等宽度溢出 → 限制最大宽度。
3. 第三轮（正式用语）：960 宽时顶栏参数徽章遮挡“批量测算”导航 → 剩余宽度不足时隐藏徽章（状态栏仍显示）；指标卡说明变长被截断 → 缩短为“其中税费 x”“预扣率 20%”“= 收入 − 应预扣预缴税额”；设置的增值税分组加入三项附加税费后需滚动 → 拆为“增值税”“附加税费”两组。
4. 第四轮（逐项确认）：设置改为逐项 ✔ ✖ 确认、去掉“保存 / 取消”；左侧导航改为“计税口径 / 计算规则 / 通用”两级结构并去掉状态图例；“增值税”页的分组标题与导航同名 → 改为“征收率”“增值税起征点”。浅色、深色各页截图复核通过。
5. 第五轮（附加税费减征与合计比例）：附加税费页改为“合计比例卡片 / 减征优惠 / 征收项目 / 计税依据”；“是否征收”改用单选（否在前，否隐藏配置）；单项“默认”改为填入后待确认。浅色、深色截图复核通过。
6. 第六轮（去掉口径徽章、三项默认征收、城建档位税率可改）：去掉设置各页与规则面板的口径状态徽章和“已修改”徽章（见第 5 节），标签列 / 控件列加宽，右侧不再留空；附加税费三项默认“是”，合计卡片默认 6% → 3%；城建三档每档右侧带税率输入框，修改档位税率时输入框旁常驻“（默认：x%）”。截图见 `/workspace/shots/v7/`。
7. 第七轮（KPI 按页区分、增值税必有）：三页结果区 KPI 按“输入不做卡片、缺的关键结果补上”调整（见组件清单）；增值税税额卡片必有，附加税费合计做独立卡片；宽屏一行 / 中等 3+2 / 窄屏自适应。截图见 `/workspace/shots/v7/`（含三页默认结果）。
