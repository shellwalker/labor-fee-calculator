# 用语规范（原用语 → 正式用语）

本工具界面（桌面端、Web、CLI、批量结果列）与文档统一使用下表的“正式用语”。正式用语尽量采用法律法规、税务总局公告和自然人电子税务局（扣缴端）的原文措辞。官方没有对应术语的（如“企业总支出”“税后实发金额”），按业务含义取名，并在“说明”列注明。

> 本表只规范用语，不构成税务意见。链接为 2026-10-21 查阅的官方页面。

## 1. 页面与导航

导航栏使用短标题（4 字），页面标题显示完整名称。

| 原用语 | 导航短标题 | 页面完整标题 | 说明 |
|---|---|---|---|
| 正算 | 收入计算 | 按不含增值税收入计算 | 以不含增值税收入为输入，计算其余各项 |
| 反算 | 实发测算 | 按税后实发金额测算 | “测算”指由结果求输入，区别于直接“计算” |
| 按总成本 / 按企业总成本正算 | 支出测算 | 按企业总支出测算 | 见下表“企业总支出” |
| 批量 / 批量计算 | 批量测算 | 批量测算 | — |
| 口径 / 默认口径 / 计算口径 | 计算参数 / 内置默认参数 | — | “口径”在官方文本中多用于统计，此处实指可配置参数 |

## 2. 金额与字段

| 原用语 | 正式用语 | 依据 | 说明 |
|---|---|---|---|
| 不含税收入 | **不含增值税收入** | 财税〔2018〕164号第三条“以不含增值税的收入减除20%的费用”（引自上海税务：[自然人电子税务局劳务报酬申报指引](https://www.shhk.gov.cn/qyfwy/030002/030002001/030002001002/20250108/7b898bcc-d1ef-4d70-951a-7276df938c23.html)） | 明确“不含”的是增值税 |
| 增值税 | **增值税税额** | [增值税法实施条例](https://www.gov.cn/zhengce/content/202512/content_7053149.htm) | 金额字段用“税额”，税种名用“增值税” |
| 增值税税率 1% | **征收率 1%（优惠征收率）** | [财政部 税务总局公告2026年第10号](https://www.mof.gov.cn/jrttts/202602/t20260203_3983175.htm) 第三条（三）6：“依照3%征收率减按1%征收率征收增值税” | 小规模纳税人适用“征收率”，不是“税率”；**用户已确认** |
| 征收门槛 | **增值税起征点** | 2026年第10号公告第一条（二）：“按次纳税的，起征点为每次（日）销售额1000元” | 原文档曾写“不是法定起征点”，经核实 1000 元与现行按次纳税起征点一致，已改正 |
| 低于门槛不征收 | **未达到增值税起征点，不征收增值税及附加税费** | 同上；[增值税法实施条例](https://www.gov.cn/zhengce/content/202512/content_7053149.htm)第四十四条“销售额达到起征点的” | “达到”含本数 |
| 附加税 / 附加税合计 | **增值税附加税费**（合计） | 城建税、教育费附加、地方教育附加均以实际缴纳的增值税税额为依据（见下三行） | “附加税”不是正式税种名；三项中只有城建税是“税”，另两项是“费”，故称“附加税费” |
| 附加税 3% | **教育费附加 3%** | [征收教育费附加的暂行规定](https://xzfg.moj.gov.cn/front/law/detail?LawID=102)第三条：“教育费附加率为3%” | **用户已确认**：原“附加税 3%”即教育费附加 |
| （新增） | **城市维护建设税** | [城市维护建设税法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5193055/content.html)第二条（计税依据）、第四条（7% / 5% / 1%） | 默认征收【用户已确认】；按纳税人所在地选择档位：纳税人所在地在市区 7%、在县城或镇 5%、不在市区县城或镇 1%，默认档位“不在市区、县城或者镇”1%【用户已确认】；各档税率可修改（默认法定税率） |
| （新增） | **地方教育附加** | [财综〔2010〕98号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5194201/content.html)：征收标准为实际缴纳增值税等税额的 2% | 默认征收，2%【用户已确认】 |
| 减半 / 优惠 | **减征优惠**；“享受减征优惠：否 / 是”、**减征比例** | [财政部 税务总局公告2023年第12号](https://www.mof.gov.cn/jrttts/202308/t20230802_3899936.htm)第二条“减半征收……城市维护建设税……教育费附加、地方教育附加” | 默认享受、减征比例 50%；通称“六税两费”减免 |
| 费率（减半后） | **法定费率** / **实际征收率** | 同上 | 实际征收率 = 法定费率 × (1 − 减征比例)；明细列“减征前金额”“减征额” |
| 增值税附加汇总比例 | **附加税费合计比例**（占计税依据） | — | 各征收项目法定费率之和为“减征前”，实际征收率之和为“减征后”（如 12% → 6%） |
| 计征 / 不计征 | **是否征收：否 / 是** | — | 设置界面用单选按钮，“否”在前 |
| 计税基数（增值税额） | **计税依据：实际缴纳的增值税税额** | 城市维护建设税法第二条 | — |
| 企业总成本 | **企业总支出** | 无官方术语 | 指企业为该笔劳务报酬承担的全部支出（不含增值税收入 + 增值税税额 + 增值税附加税费）；“成本”在会计上另有含义，故改为“支出”（**待用户决定**） |
| 收入额（指输入的每次收入） | **每次收入** | [国家税务总局公告2018年第61号](https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3963396/content.html)第八条：“每次收入不超过四千元的……” | 官方“收入额” = 收入 − 减除费用，与原字段含义不同，故改名 |
| 减除费用 | 减除费用（不变） | 61号公告第八条 | — |
| 应纳税所得额 | **预扣预缴应纳税所得额** | 61号公告第八条“以每次收入额为预扣预缴应纳税所得额”；[2018年第56号公告](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194836/content.html) | 区别于年度汇算的应纳税所得额 |
| 税率 / 预扣税率 | **预扣率** | 61号公告附件《个人所得税预扣率表二》 | — |
| 速算扣除 | **速算扣除数** | 同上 | — |
| 个税 / 代扣个税 | **应预扣预缴税额** | 56号公告：“劳务报酬所得应预扣预缴税额＝预扣预缴应纳税所得额×预扣率－速算扣除数” | 页面分组标题用“个人所得税（居民个人劳务报酬所得预扣预缴）” |
| 实际到手 / 到手金额 | **税后实发金额** | 无官方术语 | 不含增值税收入 − 应预扣预缴税额；官方无对应名称（**待用户决定**） |
| 每笔 / 一笔 | 每次（每笔单独计算，视为一次） | [个人所得税法实施条例](https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194444/content.html)第十四条 | 同一项目连续性收入应按月合并，本工具不合并 |
| 劳务报酬 | 劳务报酬所得 | 个人所得税法实施条例第六条 | 作为所得项目名时使用 |

## 3. 状态、提示与结果

| 原用语 | 正式用语 | 说明 |
|---|---|---|
| 精确 / 可精确达到 | 精确匹配 | 测算结果再计算回去与目标一致 |
| 不可精确达到 | 无法精确匹配，差额 x | — |
| 真空区间 / 空白区间 / 空位 | 不可达区间 / 不可达金额 | 起征点形成的称“不可达区间”；按分舍入形成的称“不可达金额” |
| 总成本不可达 | 总支出不可达 | 批量“测算状态”取值 |
| 错误 | 数据错误 | 批量“测算状态”取值 |
| 校准状态 | 测算状态 | 批量结果列名 |
| 反算结果（文件后缀） | 测算结果 / 计算结果 | 按税后实发金额测算输出 `原名_测算结果`，其余输出 `原名_计算结果` |
| 校验通过 | 校验通过：企业总支出 = 不含增值税收入 + 增值税税额 + 附加税费 … | 写明校验的等式 |

| 输入类型 | 正式列名（默认） | 同时接受的旧列名 |

## 5. 待用户决定的用语

1. “企业总支出”（或保留“企业总成本”、改为“企业承担总额”）。
2. “税后实发金额”（或“实发金额”“税后收入”）。
3. 导航短标题“收入计算 / 实发测算 / 支出测算 / 批量测算”。
4. 个税字段“每次收入”（或“劳务报酬收入”）。
5. 扣缴端把一般劳务报酬列为“劳务报酬（不适用累计预扣法）”；如有实习学生、保险营销员等适用累计预扣法的人员，本工具不适用。
